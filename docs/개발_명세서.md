# [개발 명세서 v4.0] 능동형 피싱/스캠 예방 및 AI 위협 수집 플랫폼 (MVP Edition)

## 1. 프로젝트 개요

### 1.1 프로젝트 정의

사용자의 동의 하에 **AI Agent(Gemini 2.5 Flash)**가 수집한 최신 피싱 사례와 사용자 취향 정보를 결합하여 모의 훈련을 제공하는 **웹 기반 서비스**. MVP 단계에서는 비용이 발생하지 않는 인프라를 활용하여 핵심 기능을 검증한다.

### 1.2 개발 목적

1. **AI 위협 인텔리전스 확보**: 경량화 고성능 모델인 `Gemini 2.5 Flash`를 활용해 웹상의 위협 정보를 저비용/고효율로 수집 및 구조화.
2. **Zero-Cost MVP 검증**: 무료 개발 도구와 호스팅 서비스를 활용하여 초기 투자 비용 없이 서비스의 시장성(PMF)을 확인.
3. **LLM 기반 개인화**: 사용자 취향을 LLM으로 증강하고 피싱 취약점을 분석하여 맞춤형 훈련 제공.

### 1.3 타겟 사용자

* **MVP 타겟**: 20대 디지털 네이티브 (웹 접근성이 높고 새로운 보안 트렌드에 민감).

---

## 2. 시스템 구성 및 아키텍처 (Cost-Effective Architecture)

### 2.1 서비스 흐름도

1. **사용자 가입**: 이메일만 입력하면 자동 가입/로그인.
2. **설문조사**: 3단계 온보딩 (기본 정보 → 취향 선택 → LLM 증강).
3. **취약점 분석**: Gemini가 사용자 프로필 기반 피싱 취약점 분석.
4. **훈련 발송**: 관리자가 시뮬레이션 이메일 발송.
5. **반응 분석**: 이메일 열람, 링크 클릭, 정보 입력 추적.

### 2.2 기술 스택 (Zero-Cost Strategy)

* **AI & Agent Model**:
  * **Threat Collector/Scenario Gen/Vulnerability Analysis**: **Gemini 2.5 Flash** (무료 API 티어 활용).

* **Frontend (Web)**:
  * **Framework**: React.js + TailwindCSS + Vite.
  * **Hosting**: **Vercel** (Hobby Plan - 무료 호스팅 및 SSL 제공).

* **Backend**:
  * **Framework**: Python FastAPI + SQLAlchemy.
  * **Hosting**: **Render** (Free Tier).

* **Database**:
  * **RDBMS**: **SQLite** (로컬 경량 DB, MVP 빠른 검증용).

* **Messaging**:
  * **Email**: **Gmail SMTP** (일 500건 제한, 무료).

## 3. 상세 기능 명세 (MVP Specs)

### 3.1 AI 위협 수집 에이전트 (Powered by Gemini 2.5 Flash)

1. **경량화 수집 파이프라인**:
   * RSS Feed 및 보안 뉴스 헤드라인 파싱.
   * 수집된 텍스트를 **Gemini 2.5 Flash**에 입력하여 `[유형, 핵심 키워드, 유인 문구]` 형태로 분석.

2. **사례 DB 적재**:
   * SQLite에 위협 사례 원문과 분석된 JSON 데이터를 저장.

### 3.2 사용자 웹 모듈 (Web Frontend)

1. **반응형 웹 인터페이스**:
   * 모바일/PC 환경에 최적화된 회원가입 및 대시보드 웹 페이지.

2. **이메일 전용 로그인**:
   * 이메일 입력만으로 자동 가입/로그인 통합.

3. **3단계 온보딩 설문**:
   * 기본 정보 (연령대, 성별, 직업, 위치)
   * 취향 선택 (카테고리 다중 선택)
   * LLM 증강 (최대 10회, 조기 종료 가능)

4. **취약점 분석 페이지**:
   * Gemini가 분석한 피싱/스캠 취약점 결과 표시.

5. **관리자 대시보드**:
   * 사용자 목록, 훈련 스케줄, 시나리오 미리보기, 통계.

### 3.3 피싱 시뮬레이션 및 발송

1. **시나리오 생성**:
   * Gemini 2.5 Flash가 사용자 취향/피해 사례 기반 피싱 이메일 생성.

2. **SMTP 발송 엔진**:
   * Python `smtplib` 라이브러리로 Gmail SMTP 발송.
   * 트래킹 픽셀 및 링크 래핑으로 열람/클릭 추적.

3. **행동 추적**:
   * 이메일 열람, 링크 클릭, 더미 페이지 체류 시간, 정보 입력 여부 기록.

## 4. 데이터베이스 설계 (SQLite 최적화)

MVP의 빠른 개발과 테스트를 위해 SQLite를 사용한다.

* **Users**: ID, 이메일, 연령대, 성별, 보안 점수.
* **UserProfiles**: 나이, 직업, 위치, 취향, LLM 증강 취향, 취약점 분석 결과.
* **ContentCategories**: 설문조사 카테고리 목록.
* **PhishingScenarios**: LLM 생성 피싱 시나리오.
* **SimulationResults**: 시뮬레이션 발송 및 추적 결과.
* **TrainingSchedules**: 훈련 예정 스케줄.

자세한 스키마는 `@01_DATA_MODEL.md` 참조.

## 5. 구현 가이드 (Implementation Note)

> **MVP 진행 시 주의사항:**
> 1. **SMS 제외**: 문자 발송은 건당 비용이 발생하므로, MVP에서는 **이메일 피싱**에 집중.
> 2. **콜드 스타트**: Render 무료 티어는 15분 이상 미사용 시 서버가 잠들기 때문에, 첫 요청 시 응답이 느릴 수 있음.
> 3. **보안**: 환경 변수(.env) 관리 철저히.
> 4. **Gemini API**: `google.generativeai` 패키지가 deprecated 상태이므로 향후 `google.genai`로 마이그레이션 권장.
