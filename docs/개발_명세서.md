# [개발 명세서 v3.0] 능동형 피싱/스캠 예방 및 AI 위협 수집 플랫폼 (MVP Edition)

## 1. 프로젝트 개요

### 1.1 프로젝트 정의

사용자의 동의 하에 **AI Agent(GPT-4.1.-nano)**가 수집한 최신 피싱 사례와 사용자 취향 정보를 결합하여 모의 훈련을 제공하는 **웹 기반 서비스**. MVP 단계에서는 비용이 발생하지 않는 인프라를 활용하여 핵심 기능을 검증한다.

### 1.2 개발 목적

1. **AI 위협 인텔리전스 확보**: 경량화 고성능 모델인 `GPT-4.1.-nano`를 활용해 웹상의 위협 정보를 저비용/고효율로 수집 및 구조화.
2. **Zero-Cost MVP 검증**: 무료 개발 도구와 호스팅 서비스를 활용하여 초기 투자 비용 없이 서비스의 시장성(PMF)을 확인.

### 1.3 타겟 사용자

* **MVP 타겟**: 20대 디지털 네이티브 (웹 접근성이 높고 새로운 보안 트렌드에 민감).

---

## 2. 시스템 구성 및 아키텍처 (Cost-Effective Architecture)

### 2.1 서비스 흐름도

1. **위협 수집**: `GPT-4.1.-nano` 기반 에이전트가 주기적으로 보안 뉴스/커뮤니티 요약 (Local/Free API 활용).
2. **웹 온보딩**: 사용자가 웹 사이트에 접속하여 회원가입 및 취향 설문(Google Form 연동 또는 자체 웹 폼) 제출.
3. **훈련 발송**: 비용이 드는 SMS 대신 **이메일(Email)** 채널에 집중하여 훈련 메시지 발송.
4. **반응 분석**: 가짜 웹페이지 내 스크립트를 통해 클릭 및 행동 로깅.

### 2.2 기술 스택 (Zero-Cost Strategy)

* **AI & Agent Model**:
* **Threat Collector**: **GPT-4.1.-nano** (경량화 모델로 토큰 비용 절감 및 빠른 추론 속도 활용).
* **Scenario Gen**: GPT-4.1.-nano 또는 로컬 호스팅 LLM (Ollama + Llama3) 병행 고려.


* **Frontend (Web)**:
* **Framework**: React.js 또는 Vue.js (SPA).
* **Hosting**: **Vercel** 또는 **Netlify** (Hobby Plan - 무료 호스팅 및 SSL 제공).


* **Backend**:
* **Framework**: Python FastAPI.
* **Hosting**: **Render** (Free Tier) 또는 **Fly.io** (Free Allowance). *※참고: Free Tier는 미사용 시 절전 모드로 들어갈 수 있으나 MVP에는 무방함.*


* **Database**:
* **RDBMS + Vector**: **Supabase** (PostgreSQL + pgvector 무료 티어 제공). 사용자 정보 및 임베딩 벡터 통합 저장.


* **Messaging**:
* **Email**: **Gmail SMTP** (일 500건 제한, 무료) 또는 **Brevo(Sendinblue)** (일 300건 무료 API). *※SMS는 건당 비용이 발생하므로 MVP에서 제외.*

## 3. 상세 기능 명세 (MVP Specs)

### 3.1 AI 위협 수집 에이전트 (Powered by GPT-4.1.-nano)

1. **경량화 수집 파이프라인**:
* 무거운 크롤링 대신 RSS Feed 및 텍스트 위주 사이트(보안 뉴스 헤드라인)를 타겟팅.
* 수집된 텍스트를 **GPT-4.1.-nano**에 입력하여 `[유형, 핵심 키워드, 유인 문구]` 형태로 JSON 파싱.


2. **사례 DB 적재**:
* Supabase에 위협 사례 원문과 분석된 JSON 데이터를 저장.



### 3.2 사용자 웹 모듈 (Web Frontend)

1. **반응형 웹 인터페이스**:
* 모바일/PC 환경에 최적화된 회원가입 및 대시보드 웹 페이지 구현.


2. **취향 데이터 수집 폼**:
* 별도 백엔드 개발 공수를 줄이기 위해 초기엔 `Typeform`(무료)이나 `Tally Forms`를 임베딩하거나, React Hook Form으로 자체 구현.


3. **결과 리포트 페이지**:
* Chart.js(오픈소스 라이브러리)를 활용하여 사용자의 보안 점수를 시각화한 웹 페이지 제공.



### 3.3 피싱 시뮬레이션 및 발송

1. **이메일 템플릿 생성**:
* GPT-4.1.-nano가 생성한 피싱 문구를 HTML 이메일 템플릿에 주입.


2. **SMTP 발송 엔진**:
* Python `smtplib` 라이브러리를 사용하여 Gmail 또는 Brevo 무료 API를 통해 발송.
* *제약사항*: MVP 단계에서는 대량 발송 대신 소규모 그룹(테스터) 대상 발송으로 제한.



---

## 4. 데이터베이스 설계 (Supabase Free Tier 최적화)

무료 티어의 저장 용량 제한(주로 500MB~1GB)을 고려하여 스키마를 경량화한다.

* **Users**: ID, 이메일, 암호화된 비밀번호, 취향 태그(Array), 보안 점수.
* **Threats**: 수집된 피싱 사례 (GPT-4.1.-nano 분석 결과 JSONB).
* **Logs**: 훈련 발송 및 클릭 로그 (과거 로그는 주기적으로 삭제 or CSV 백업 후 DB에서 제거).

## 5. 수석 개발자의 구현 가이드 (Implementation Note)

> "GPT-4.1.-nano 모델을 선정하신 것은 훌륭한 선택입니다. 에이전트 작업(Agentic Workflow)에서 속도와 비용 효율성을 동시에 잡을 수 있기 때문입니다.
> **MVP 진행 시 주의사항:**
> 1. **SMS 제외**: 문자 발송은 건당 비용이 발생하므로, MVP에서는 **이메일 피싱**에 집중하십시오. '비밀번호 변경 안내', '구독 결제 영수증' 등 이메일 기반 시나리오가 20대 타겟에도 충분히 유효합니다.
> 2. **콜드 스타트**: Render 무료 티어는 15분 이상 미사용 시 서버가 잠들기 때문에, 첫 요청 시 응답이 느릴 수 있습니다. 이는 MVP 테스트 단계에서는 허용 가능한 수준입니다.
> 3. **보안**: 무료 호스팅을 쓰더라도 DB 접속 정보 등 환경 변수(.env) 관리는 철저히 해야 합니다."
